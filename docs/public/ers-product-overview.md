# ERS Product Overview

> Draft for review. Product availability and individual capabilities remain subject to release validation.

ERS (Errand Runner System) is a logistics marketplace designed to connect people who need errands completed with runners who can carry them out, with a focus on the practical realities of Lagos, Nigeria.

The current ERS product page describes an errand lifecycle that includes creating a request, runner participation, client-runner communication, and payment handling. It also describes a one-active-errand-at-a-time runner rule. These descriptions should not be read as confirmation that every capability is available in a production release.

The website presents ERS as an evolving product. Confirm implementation and release status before describing a capability as available. For current product inquiries, use the [ERS page](/platform) or [contact Wanky](/contact).
